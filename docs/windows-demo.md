# Windowsでデモを見る

Gitやプログラミングの知識は不要です。Node.jsの導入時と、初回の部品ダウンロード時はインターネット接続が必要です。

1. [Node.js公式サイト](https://nodejs.org/ja/download)から、Windows用のNode.js 24以上（LTS版を推奨）をインストールします。インストーラーの通常設定でnpmも入ります。すでに24以上が入っていればこの手順は不要です。
2. GitHubの [デモ用ブランチ](https://github.com/Hamurabidabutsu/-/tree/codex-windows-demo) を開き、緑色の **Code → Download ZIP** からPCへ保存します。非公開リポジトリの場合は、そのリポジトリを閲覧できるGitHubアカウントでログインしてください。
3. ZIPを右クリックし、**「すべて展開」**で通常のフォルダーへ展開します。
4. 展開先で **start-demo.cmd** が入っているフォルダーを開き、そのファイルをダブルクリックします。ZIP内から直接実行せず、展開先を開いてください。
5. 初回は必要な部品を取り込みます。完了するとEdge/Chromeなど、普段使うブラウザーにデモ画面が開きます。

起動中のウィンドウは開いたままにします。終了は、そのウィンドウを選んで **Ctrl+C** です。次回は **start-demo.cmd** をもう一度ダブルクリックするだけです。

自動でブラウザーが開かなければ、起動ウィンドウの **「起動しました」**に続くアドレスをブラウザーのアドレス欄にコピーします。アドレスはお使いのPC内だけを指します。他の人に送ってもそのPCの画面は開けません。

## まず試す操作

- **希望者で試す**：提供者を検索 → 提供者ページ → 会話を申請。
- **提供者で試す**：チャット → 会話を承認 → メッセージや画像を送信。相手への顔写真/学歴の開示もここで操作します。
- **管理者で試す**：管理ページ・会話の閲覧を確認。

登録・支払い・審査を最初から試す場合は、合成したメールアドレスなどで提供者アカウントを作成し、サンプル書類で申請します。デモ支払いは実際の課金をしません。デモには実在の身分証や医療情報を入れないでください。

## 起動しない場合

- **Node.jsが必要と表示される**：Node.jsのインストールを完了し、新しく起動してください。PCを再起動すると設定が反映される場合があります。
- **部品のインストールに失敗した**：インターネット接続を確認し、同じ起動ファイルを再実行します。
- **アクセス権限エラー**：ZIPを「ドキュメント」など、ご自身が書き込める通常のフォルダーへ展開してください。
- **そのほかのエラー**：エラーの文章をこのチャットへ送れば、原因を調べられます。パスワードや個人情報は含めないでください。

設定ファイルの手編集は不要です。起動ファイルはPC内だけで接続を受け付け、デモ用のデータを `data/local-demo` に保存します。既存の本番設定やデータを上書きせず、実決済用の認証情報も使用しません。

Windows用の起動ファイルを含みますが、確認に使用できる実行環境はLinuxです。共通の起動処理・初回インストール・画面表示をLinuxで検証し、Windowsのダブルクリック操作そのものは未検証です。

## 今回の更新とメールの確認

最新ZIPを同じデモ用ブランチから取得し、新しいフォルダーへ展開して起動してください。前のデモの入力を残す場合は、先に起動中のデモを終了して、前の `data/local-demo` フォルダーを新しいフォルダーの `data/local-demo` へコピーします。`node_modules` はコピーせず、起動時の自動インストールを利用してください。旧データは起動時に自動移行します。従来の一般筋肉量から骨格筋率は推測しません。

アカウント画面の「デモのメール受信欄」で自分宛ての通知を確認できます。新規の架空アカウントでは、確認メールのリンクを開き、確認ボタンを押してから通知を試します。登録画面にも非公開メールアドレスと通知設定を表示します。デモは実際のメールを送信しません。
